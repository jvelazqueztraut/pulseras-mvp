# Pulseras MVP

Proximity-based UI for detecting nearby Bluetooth Low Energy devices without pairing.

This MVP uses a simulated BLE data source so scanning, proximity updates, hiding devices, and settings can be exercised without hardware access.

## Screens

- Home empty, scanning, detected, and stopped states
- Bluetooth unavailable and permission denied
- Device details and hide confirmation
- Settings, hidden-device management, proximity, and privacy

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
